# Contributing to Grimório

Thanks for helping. Grimório is GPL-3.0; by contributing you agree your changes are released under the same licence.

## Before you start

- Open an issue first for anything bigger than a small fix.
- Never commit secrets, signing keys (`*.keystore`), `.env` files, Scryfall card images or data, or Forge files.
- Screenshots in `docs/img/` must not show personal data.

## Workflow

Set-up is in the README ([Developer setup](README.md#developer-setup)).

1. Branch from `main`; keep each pull request to one change.
2. Run the existing checks before opening it, and add a test for new behaviour.
3. Check the UI at desktop, tablet and phone widths, and in more than one language when you touch text.
4. Open the pull request against `main` describing what changed and why.

## Language

Documentation is in British English (`README.md`); the Portuguese version (`README.pt.md`) uses European Portuguese. Keep translations in step when you change the README.
